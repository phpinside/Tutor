# 海报模板说明

## 模板规格

- **尺寸**: 750x1334px (适合手机屏幕)
- **格式**: PNG
- **二维码区域**: 底部水平居中预留 200x200px 空间 (位置: x=275, y=1100)

## 模板文件

- `template-1.png`: 主模板（当前使用 Canvas 动态生成的默认模板）
- `template-2.png`: 备用模板（可选）

## 设计建议

1. 使用鲜艳的渐变背景
2. 包含品牌标识和 Logo
3. 添加吸引人的文案，例如：
   - "邀请好友，共同成长"
   - "完成任务，立即获得奖励"
4. 预留底部居中区域用于放置二维码（200x200px，距离底部约34px）
5. 使用易读的字体和高对比度的颜色

## 替换模板

将设计好的海报图片命名为 `template-1.png` 放到此目录下即可自动使用。

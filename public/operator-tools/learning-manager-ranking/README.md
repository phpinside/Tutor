# 学管榜单模板

- `background.png`：实际使用的 1055 × 1491 固定背景。保留附件的原始像素，仅替换日期、团队名称和三行团队文案所在区域。
- `blank-template.png`：使用内置 imagegen 编辑工具提取的空白模板，用于清除可编辑区域。运行时无需调用任何 AI 服务。
- `backdrop.png`：移除全部团队卡片后的完整背景底图。非六团队布局使用其中央区域，使任意数量的卡片可以平滑排列。
- 中文字体复用 `/fonts/NotoSansCJKsc-Regular.otf`，浏览器完成字体加载后才允许导出。

图像编辑提示词：保留附件的尺寸、布局、蓝金配色、Logo、主标题、奖杯、高转化/高服务/高口碑、评选依据、卡片边框和图标、底部固定文案；仅移除日期整行、六个团队的名称和三行标签右侧的可变文案，恢复对应的浅蓝、深蓝或米白底色。保留擅长学段、核心简介、亮点总结及其图标。

底图编辑提示词：在上述空白模板上，仅移除 y=453 至 y=1299 的六个团队卡片及其中的边框、标题、图标和标签；恢复连续的蓝色渐变背景和边缘金色光带。保留固定页眉和页脚，不新增分隔行、文字或卡片。

绘制坐标以原始尺寸为基准；下载使用 2 倍尺寸。卡片标题显示学管姓名，亮点总结下方新增可编辑的所属团队。保留原卡片顶部和三行标签，只延长米白色内容区域，在代码中绘制第四行标签。卡片高度 325 像素，行间距 18 像素，六位学管的海报尺寸为 1055 × 1672，下载尺寸为 2110 × 3344。其他数量按两列增加或减少行数，奇数末项居中，固定页眉和页脚不缩放。页面仅提供榜单图片下载。

每位学管的所属团队默认显示，可在表单单独关闭。关闭时不绘制第四行标签和团队名称，但保留整行高度、卡片尺寸及所有其他元素的位置；已填写的团队名称保留，重新开启后恢复显示，隐藏状态无需填写团队名称。

所有内置底图及管理员上传的底图均存放在此目录。

- 内置横版模板：`royal.jpg`（皇家典藏）、`azure.jpg`（蔚蓝荣耀）、`british.jpg`（英伦学院）、`blackGold.jpg`（黑金至尊）、`scholar.jpg`（国风书香）、`champagne.jpg`（香槟雅金）、`sunshine.jpg`（阳光成长）、`laurel.jpg`（桂冠荣耀）。
- 对应竖版模板：`royal-portrait.jpg`、`azure-portrait.jpg`、`british-portrait.jpg`、`blackGold-portrait.jpg`、`scholar-portrait.jpg`、`champagne-portrait.jpg`、`sunshine-portrait.jpg`、`laurel-portrait.jpg`。
- 管理员上传的底图命名为 `upload-<UUID>.png/jpg/webp`，避免重名覆盖。更换底图或归档模板不会删除旧文件。

共十六套无文字 A4 底图：八套横版为 3508 × 2480，八套竖版为 2480 × 3508。竖版重新组织了装饰构图，保留对应横版的配色与纹饰。文字位置保存在数据库中，由后台预览、老师端预览、模板缩略图与 PNG 导出共用的渲染器绘制。

## 内容布局

奖项名称作为顶部主标题，固定「荣誉证书」标题默认隐藏；中部依次为颁授提示、学员姓名、年级与科目，下面是颁奖词。左下方依次显示指导教练和伴学团队，右下方显示颁发单位和日期。

横版的年级与科目区域逐套校准到各底图的装饰框内。竖版在中间绘制细金边框，年级与科目均为空时自动隐藏该边框；后台可在「年级 / 科目」文字区域开关边框。年级显示为「六年级」等简洁形式，科目直接显示「数学」等名称。

新模板使用相同的内容层级作为初始布局。已有十六套内置模板通过 `20261011130000_student_certificate_content_layout` 迁移更新文字配置；历史生成图片独立保存。

## 竖版制作说明

使用内置 ImageGen，以同名横版图片为参考分别生成八张竖版底图，然后统一输出为上述尺寸的高质量 JPG。新增数据库迁移将八套竖版配置为可用模板，后台仍可调整文字区域、启停与归档。

统一提示词：生成 A4 竖版、无文字的学员奖状底图，参考对应横版风格，保留其颜色、材质、边框与装饰元素；为竖版重新构图，不旋转或拉伸横版。精致装饰集中在外缘，顶部小徽章、底部克制的勋章或书本元素；中央象牙白内容区连续留白，标题、姓名、年级科目、奖项、颁奖词和底部署名区域保持清晰，无内部牌匾或分隔线。禁止文字、字母、数字、伪文字、品牌标志和水印。每张参考图对应皇家典藏、蔚蓝荣耀、英伦学院、黑金至尊、国风书香、香槟雅金、阳光成长、桂冠荣耀其中一种风格。

部署时，此目录必须可写并持久保存。Docker 可挂载持久目录；多实例部署需共享此目录。Vercel 等只读、临时文件系统环境不支持此本地上传方式。

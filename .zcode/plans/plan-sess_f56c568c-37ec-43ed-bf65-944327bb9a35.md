# 合并证明相关菜单 + 后台菜单加图标

## 一、菜单合并（3 → 1，内部标签页切换）
路由重组到统一前缀 `/admin/certificates` 下（git mv 保留历史）：
- `/admin/internship-certificates` → **`/admin/certificates`**（申请列表，含盖章开具/打回/下载）
- `/admin/certificate-templates` → **`/admin/certificates/templates`**（模板列表 + 新建/编辑页）
- `/admin/certificate-companies` → **`/admin/certificates/companies`**（开具单位管理）

- 新增 `CertificateSubNav` 顶部标签页组件（申请列表 / 证明模板 / 开具单位，pill 高亮当前页），插入到这 4 个页面（申请列表、模板列表、模板编辑、单位管理）顶部
- 侧边菜单只剩一项「📄 证明开具」指向 `/admin/certificates`
- 旧路径不做重定向（内部后台，走菜单导航）

## 二、所有后台菜单加图标
`AdminLayoutClient.tsx` 的 `MENU_ITEMS` 增加 `icon` 字段，渲染为 `icon + label`（emoji 风格与现有后台一致）：
👨‍🏫 老师管理 / 👥 运营人员 / 🤝 邀请管理 / 💰 提现管理 / 📄 证明开具 / 📊 案例记录 / 🎥 会议管理 / ⚙️ 系统配置

## 三、引用同步
- `middleware.ts`：ROUTE_PERMISSIONS 三条合并为 `'/admin/certificates': ['super_admin']`
- server actions 的 `revalidatePath`：certificate.ts → `/admin/certificates`；certificateTemplate.ts → `/admin/certificates/templates`；certificateCompany.ts → `/admin/certificates/companies`
- 页面内 Link/redirect：模板列表的「新建/编辑」链接、编辑页返回链接等改到新路径
- API 路径（`/api/admin/...`）保持不变，不受影响

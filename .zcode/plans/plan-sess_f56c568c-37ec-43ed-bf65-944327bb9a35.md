# 表单预填：日期默认值 + 身份信息自动带出

## 一、日期默认值做成模板字段的通用配置（不是写死劳务单）
- `TemplateFieldDef` 增加 `default` 属性；日期字段支持相对日期令牌：`today` / `lastMonthStart`（上月1日）/ `lastMonthEnd`（上月最后一日，按用户本地时区计算）
- 新增 `getTemplateFieldDefault(field, now)` 纯函数解析默认值（certificate-template.ts，客户端可用）
- **劳务完成确认单种子模板**：开始日期默认 `lastMonthStart`、结束日期默认 `lastMonthEnd` → 9月5日进入页面自动填好 **8月1日 至 8月31日**，可修改
- 管理端模板编辑器：日期字段出现「默认日期」下拉（无 / 今天 / 上月首日 / 上月末日）；server actions 校验令牌合法性（仅日期字段支持默认值）

## 二、身份信息自动带出（零新表）
- 数据本来就已存在申请记录里：进入类型页时服务端查询该老师**最近一条有姓名的申请**（跨类型），取出 姓名/性别/身份证
- 表单初始化优先级：历史申请身份信息 > 老师账号资料（姓名/性别） > 字段默认值 > 空；全部可再次编辑
- 提交新申请后数据自然更新，下次开具自动用最新填写的身份信息
- 不动 Teacher 表、不加新表，金额/项目名称等业务字段不预填（每次申请不同）

## 三、关于「表单展示模板占位符字段」
现有实现已支持（模板 fields 定义 → 用户端动态渲染表单），本次叠加预填能力。

## 文件改动
- `src/lib/certificate-template.ts`（default 属性 + 解析函数）
- `[type]/page.tsx`（查询历史身份并传入）、`[type]/CertificateApplyClient.tsx`（initValues 叠加默认值与身份信息）
- 管理端 `CertificateTemplateForm.tsx` + `actions/certificateTemplate.ts`（默认值编辑与校验）
- 种子脚本（劳务单日期默认值）

## 验证
`npm run build`；种子重跑后打开劳务单页确认日期默认为上月区间、身份信息自动填好。

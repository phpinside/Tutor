# 快捷登录助手(Bookmarklet)实现计划

**目标**:在 A 网站(tutor.bytemath.cn)的常用工具中新增「快捷登录助手」,用户把按钮拖到 Chrome/Edge 书签栏后,以后打开 B 网站(manage.dingbanxue.com)点击书签即可自动加载 A 的 `/b-init.js`,写入 `DeviceId`/`RoleTag` 并刷新页面。

## 新建文件

### 1. `src/lib/bookmarkHelperConfig.ts` — 集中配置
```ts
export const BOOKMARK_HELPER_CONFIG = {
  bookmarkName: '🚀 快捷登录助手',
  // A 网站(本系统)域名,改这里即可
  aDomain: 'https://tutor.bytemath.cn',
  // B 网站(目标管理后台)
  targetWebsite: 'https://manage.dingbanxue.com',
  targetHosts: ['manage.dingbanxue.com', 'www.manage.dingbanxue.com'],
  storage: {
    DeviceId: 'e29dd099ed5c908a68cae29cec7a5313',
    RoleTag: 'DeliveryCenter',
  },
  reloadAfterSuccess: true,
}
```
纯常量模块(不引 Prisma,客户端组件可安全导入),遵循现有 SCREAMING_SNAKE_CASE + 中文注释风格。

### 2. `src/app/onboarding/tools/quick-login-helper/page.tsx` — 页面(server component)
- 复用现有惯例:读 `teacherId` cookie,无则 `redirect('/auth/login')`;`animate-fade-in` 包裹、`← 返回工具列表` 链接、标题「快捷登录助手」、副标题「安装一次,以后打开 B 网站点击书签即可完成初始化」。
- 渲染 `QuickLoginHelperClient`。

### 3. `src/app/onboarding/tools/quick-login-helper/QuickLoginHelperClient.tsx` — 交互部分(client component)
由配置生成 Bookmarklet(单行、无换行、`javascript:` 开头):
```javascript
javascript:(()=>{const s=document.createElement('script');s.src='https://tutor.bytemath.cn/b-init.js?t='+Date.now();s.onload=()=>s.remove();s.onerror=()=>alert('快捷登录助手加载失败,请检查网络或联系管理员');(document.head||document.documentElement).appendChild(s)})()
```
包含:
- **核心拖拽按钮**:`<a draggable href={bookmarklet}>`,文本「🚀 快捷登录助手」,Tailwind 实现 hover 阴影/圆角/缩放动效,`title` 提示;`onClick` 阻止默认行为并弹页面内 Toast「请把这个按钮拖到浏览器书签栏,而不是直接点击。」;附近提示「按住上面的按钮,拖到浏览器书签栏。」(强调是拖动不是点击)
- **演示示意图**:用样式化 div(仿按钮 + 向下箭头 + 「Chrome 书签栏」条 + ⭐ 图标)直观展示拖动安装
- **使用步骤**:6 步 + 快捷键提示(`Ctrl+Shift+B` / `⌘+Shift+B`)
- **复制书签代码**按钮:复制原始 bookmarklet 字符串(成功提示「已复制,可以手动新建书签并粘贴到网址栏。」,失败提示),旁边「查看手动安装教程」折叠面板(新建书签 → 名称 → 粘贴 URL → 保存)
- **CSP 提示**小字:目标网站启用 CSP 时远程脚本可能无法加载,需改用本地 Bookmarklet 或扩展方案(不绕过安全机制)
- 页面内轻量 Toast(复用复制反馈状态,不引第三方库)

### 4. `public/b-init.js` — 核心业务脚本(纯原生 JS,IIFE,零依赖)
- 顶部注释说明用途 + CSP 限制说明
- 内部集中 `CONFIG`:`allowedHosts`、`storage`(DeviceId/RoleTag)、`reloadAfterSuccess: true`
- 运行锁 `window.__B_SITE_HELPER_RUNNING__` 防重复执行
- `location.hostname` 校验,不在白名单 → Toast「请先打开 B 网站后再使用本工具。」并停止
- `try/catch` 逐项写入 localStorage(不清空原有数据、不调用 `clear()`),写后立即 `getItem` 验证;localStorage 不可用 → 「无法写入浏览器数据,请检查浏览器隐私设置。」;结果不一致 → 「初始化失败,请重新尝试。」
- 成功 → 右上角 Toast「✓ B网站初始化成功」(inline style、fixed、z-index 2147483647、2.5s 自动消失),`reloadAfterSuccess` 为 true 时 800ms 后 `location.reload()`
- 不用 `eval()`/`new Function()`,不读密码/Cookie、不上传任何数据

## 说明
- `public/b-init.js` 按需求保持完全独立(内置自己的 CONFIG),与 TS 配置用注释互指,避免互相引用
- 书签按钮 `href` 由 React 自动做 HTML 属性转义(如 `=>` 中的 `>` 编码为 `&gt;`,浏览器解析后还原),拖入书签栏后 URL 正确;复制功能复制的是未转义的原始字符串
- 本地开发测试时可临时把配置 `aDomain` 改为 `http://localhost:3000`
